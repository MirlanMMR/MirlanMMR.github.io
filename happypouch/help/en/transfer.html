Moving from another app

Records from another budget app come over as one file. Categories and currencies are created for you; there is no need to start from zero.

What comes over

  • Expense and income records: date, amount, category, subcategory, currency, note.
  • Categories and currencies you do not have yet: the app creates them and shows the list before loading.

Transfers between wallets do not come over: they are skipped, and the app says how many there were. Records that are already in Happy Pouch are not added a second time.

Step 1. Save a file in the old app

Find “Export” in it, usually in the settings or in the data section. Excel (XLSX) and CSV work best. Save the file to the phone.

It has to be an export to a table, not a “backup”. Happy Pouch cannot read another app's backup.

Step 2. Open the file in Happy Pouch

“Settings” → “Data transfer” → “Choose file”. In an empty app the same button is on “Home”: “Transfer data / import statement”.

Step 3. Check the columns

The “Import transactions” screen opens. The app matches the file's columns to its own fields: “Date”, “Amount”, “Category”, “Subcategory”, “Currency”, “Note”. Next to each field is a button with the name of the column that goes into it.

  • Wrong column: tap the button and pick the right one.
  • The first row of the file is shown under the list, so you can see whether everything is in place.
  • If expenses and income sit in two different columns, switch “One amount column” to “Income and expense separately”.
  • If there is no column with the type, negative amounts count as expenses and positive ones as income.

For dates like 05/10/2026 you can set the order: “Day/month” or “Month/day”. “Auto” is usually enough.

If the file has no currency column, pick one currency for all records.

Step 4. Look at the summary and load

Before loading, the app shows what will happen: how many records will be added and for which period, how many are skipped and why, which categories and currencies will appear. Below are three records as a sample. If everything is right, tap “Import”.

Which files work

FormatWhere it usually comes from
Excel XLSX and XLSexport from most budget apps; the most reliable option
CSVapp exports, statements; separator and encoding are detected automatically
OFX, QFX, QBObank statements
QIFolder finance programs
SQLiteGnuCash and Money Manager databases

The file must be no larger than 30 MB.

If it does not work

  • “This isn't a table but a proprietary file”. You picked another app's backup. Go back to that app and find the export to CSV or Excel.
  • “This is a JSON file”. It is a backup of Happy Pouch itself. It is loaded elsewhere, in “Settings”: “Backups on this phone” → “Restore”.
  • Dates or amounts are not recognised. The app shows examples of such rows. Check that the right column is picked for the date and the amount, and the day and month order.
  • Columns are mixed up or there are too many. Open the file in Excel or Google Sheets and keep the columns “Date”, “Amount”, “Category”, “Note”.

If the file looks like nothing familiar, you can give it to any AI assistant and ask it to turn the file into a CSV table with the columns “Date”, “Amount”, “Category”, “Note”. Keep in mind that the service you send it to will see the file with your spending.
