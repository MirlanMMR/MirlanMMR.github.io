Moving from another app

Records from another budget app move over as a single file. Categories and currencies are created for you, so there is no need to start from zero.

What gets transferred

  • Expense and income records: date, amount, category, subcategory, currency, note.
  • Categories and currencies you do not have yet. The app creates them and shows you the list before importing.

Transfers between wallets are not imported: they are skipped, and the app tells you how many there were. Records that are already in Happy Pouch are not added a second time.

Step 1. Export a file from your old app

Look for “Export” in the old app, usually in Settings or in a data section. Excel (XLSX) and CSV work best. Save the file to your phone.

You need an export to a table (a spreadsheet), not a “backup”. Happy Pouch cannot read another app's backup.

Step 2. Open the file in Happy Pouch

“Settings” → “Data transfer” → “Choose file”. In an empty app the same button is on “Home”: “Transfer data / import statement”.

Can't see the file in the list? The file picker opens where you were last time, often in “Photos”. Tap ☰ at the top left and open “Recent”: a freshly received file is there. For a file sent through WhatsApp or Telegram, also look in “Downloads” or “Documents”. If it is not in “Recent”, open the file in the messenger and save it to the phone, then try again.

Step 3. Check the columns

The “Import transactions” screen opens. At the top it says what kind of file it looks like and how many rows it has. Below is the list of the app's fields: “Date”, “Amount”, “Category”, “Subcategory”, “Currency”, “Note”. The app has already matched a column of your file to each field by its header.

How to see which column is chosen. To the right of each field is a rounded button with an outline. It shows the name of the column from your file, for example “Date” or “Transaction date”. If it shows a dash “—”, no column is chosen for that field.

How to choose another column. Tap that button to the right of the field. A list opens: the first line is “— don't use”, then all the columns of your file. Tap the one you need. For example, the “Date” field shows “Created date” and you need “Transaction date”: tap the button and pick “Transaction date”.

How to check the result. Under the list of fields it says: “First row of the file: date …, amount …”. That is what the app read from the first row of your file with the chosen columns. If the date or amount there looks wrong, change the column of the matching field.

  • If expenses and income sit in two different columns in the file, switch “One amount column” to “Income and expense separately”. Then two fields appear in place of the single “Amount”: “Expense column” and “Income column”.
  • If the file has no column with the type, negative amounts count as expenses and positive ones as income.
  • If a field is not needed (for example “Subcategory”), pick “— don't use” in its list.

For dates like 05/10/2026, set the date order below the list: “Auto”, “Day/month” or “Month/day”. “Auto” is usually enough.

If the file has no currency column, choose one currency for all records below by tapping the button with its code.

Step 4. Review the summary and import

Before importing, the app shows what will happen: how many records will be added and for which period, how many will be skipped and why, and which categories and currencies will be created. Below that are three sample records. If everything looks right, tap “Import”.

Which files work

FormatWhere it usually comes from
Excel XLSX and XLSexport from most budget apps; the most reliable option
CSVapp exports, statements; separator and encoding are detected automatically
OFX, QFX, QBObank statements
QIFolder finance programs
SQLiteGnuCash and Money Manager databases

The file can be up to 30 MB.

If it does not work

  • “This isn't a table but a proprietary file”. You picked another app's backup. Go back to that app and look for an export to CSV or Excel.
  • “This is a JSON file”. It is a backup of Happy Pouch itself. Restore it from “Settings” instead: “Backups on this phone” → “Restore”.
  • Dates or amounts are not recognized. The app shows examples of such rows. Check that the right columns are picked for the date and the amount, and that the day/month order is right.
  • Columns are mixed up, or there are too many. Open the file in Excel or Google Sheets and keep only the columns “Date”, “Amount”, “Category” and “Note”.

If the file's format is unfamiliar or messy, you can give it to an AI assistant and ask it to turn it into a CSV table with the columns “Date”, “Amount”, “Category” and “Note”. Keep in mind that the service you send it to will see your spending.
