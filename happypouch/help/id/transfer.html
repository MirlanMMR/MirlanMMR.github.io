Pindah dari aplikasi lain

Catatan dari aplikasi anggaran lain pindah sebagai satu file. Kategori dan mata uang dibuatkan untuk Anda, jadi tidak perlu mulai dari nol.

Apa yang dipindahkan

  • Catatan pengeluaran dan pemasukan: tanggal, jumlah, kategori, subkategori, mata uang, catatan.
  • Kategori dan mata uang yang belum Anda punya. Aplikasi membuatnya dan menampilkan daftarnya sebelum mengimpor.

Transfer antardompet tidak diimpor: dilewati, dan aplikasi memberi tahu berapa jumlahnya. Catatan yang sudah ada di Happy Pouch tidak ditambahkan untuk kedua kalinya.

Langkah 1. Ekspor file dari aplikasi lama Anda

Cari “Ekspor” di aplikasi lama, biasanya di Pengaturan atau di bagian data. Excel (XLSX) dan CSV paling baik. Simpan file ke ponsel Anda.

Anda perlu ekspor ke tabel (spreadsheet), bukan “cadangan”. Happy Pouch tidak bisa membaca cadangan aplikasi lain.

Langkah 2. Buka file di Happy Pouch

“Pengaturan” → “Pemindahan data” → “Pilih file”. Di aplikasi yang kosong tombol yang sama ada di “Beranda”: “Pindahkan data / impor rekening koran”.

Tidak melihat file di daftar? Pemilih file terbuka di tempat terakhir Anda berada, sering kali di “Foto”. Ketuk ☰ di kiri atas dan buka “Terbaru”: file yang baru diterima ada di sana. Untuk file yang dikirim lewat WhatsApp atau Telegram, lihat juga di “Unduhan” atau “Dokumen”. Jika tidak ada di “Terbaru”, buka file di aplikasi pesan dan simpan ke ponsel, lalu coba lagi.

Langkah 3. Periksa kolom

Layar “Impor transaksi” terbuka. Di bagian atas tertulis file itu tampak seperti jenis apa dan berapa barisnya. Di bawahnya daftar kolom aplikasi: “Tanggal”, “Jumlah”, “Kategori”, “Subkategori”, “Mata uang”, “Catatan”. Aplikasi sudah mencocokkan satu kolom dari file Anda dengan setiap bidang menurut judulnya.

Cara melihat kolom mana yang dipilih. Di sebelah kanan setiap bidang ada tombol bulat berbingkai. Tombol itu menampilkan nama kolom dari file Anda, misalnya “Tanggal” atau “Tanggal transaksi”. Jika menampilkan tanda hubung “—”, tidak ada kolom yang dipilih untuk bidang itu.

Cara memilih kolom lain. Ketuk tombol di sebelah kanan bidang itu. Daftar terbuka: baris pertama adalah “— jangan gunakan”, lalu semua kolom file Anda. Ketuk yang Anda butuhkan. Misalnya, bidang “Tanggal” menampilkan “Tanggal dibuat” dan Anda butuh “Tanggal transaksi”: ketuk tombolnya dan pilih “Tanggal transaksi”.

Cara memeriksa hasilnya. Di bawah daftar bidang tertulis: “Baris pertama file: tanggal …, jumlah …”. Itulah yang dibaca aplikasi dari baris pertama file Anda dengan kolom yang dipilih. Jika tanggal atau jumlah di sana tampak salah, ganti kolom bidang yang bersangkutan.

  • Jika pengeluaran dan pemasukan berada di dua kolom berbeda dalam file, ubah “Satu kolom jumlah” menjadi “Pemasukan dan pengeluaran terpisah”. Lalu dua bidang muncul menggantikan “Jumlah” tunggal: “Kolom pengeluaran” dan “Kolom pemasukan”.
  • Jika file tidak punya kolom jenis, jumlah negatif dihitung sebagai pengeluaran dan jumlah positif sebagai pemasukan.
  • Jika sebuah bidang tidak diperlukan (misalnya “Subkategori”), pilih “— jangan gunakan” di daftarnya.

Untuk tanggal seperti 05/10/2026, atur urutan tanggal di bawah daftar: “Otomatis”, “Hari/bulan”, atau “Bulan/hari”. “Otomatis” biasanya sudah cukup.

Jika file tidak punya kolom mata uang, pilih satu mata uang untuk semua catatan di bawahnya dengan mengetuk tombol berisi kodenya.

Langkah 4. Tinjau ringkasan dan impor

Sebelum mengimpor, aplikasi menampilkan apa yang akan terjadi: berapa catatan akan ditambahkan dan untuk periode apa, berapa yang akan dilewati dan mengapa, serta kategori dan mata uang apa yang akan dibuat. Di bawahnya ada tiga catatan contoh. Jika semuanya tampak benar, ketuk “Impor”.

File mana yang bisa dipakai

FormatBiasanya berasal dari mana
Excel XLSX dan XLSekspor dari kebanyakan aplikasi anggaran; pilihan paling andal
CSVekspor aplikasi, rekening koran; pemisah dan pengodean terdeteksi otomatis
OFX, QFX, QBOrekening koran bank
QIFprogram keuangan lama
SQLitebasis data GnuCash dan Money Manager

File bisa sampai 30 MB.

Jika tidak berhasil

  • “Ini bukan tabel melainkan file berformat khusus”. Anda memilih cadangan aplikasi lain. Kembali ke aplikasi itu dan cari ekspor ke CSV atau Excel.
  • “Ini file JSON”. Ini adalah cadangan Happy Pouch sendiri. Pulihkan dari “Pengaturan”: “Cadangan di ponsel ini” → “Pulihkan”.
  • Tanggal atau jumlah tidak dikenali. Aplikasi menampilkan contoh baris seperti itu. Periksa apakah kolom yang tepat dipilih untuk tanggal dan jumlah, dan apakah urutan hari/bulan sudah benar.
  • Kolom tercampur, atau terlalu banyak. Buka file di Excel atau Google Sheets dan simpan hanya kolom “Tanggal”, “Jumlah”, “Kategori”, dan “Catatan”.

Jika format file asing atau berantakan, Anda bisa memberikannya ke asisten AI dan memintanya mengubahnya menjadi tabel CSV dengan kolom “Tanggal”, “Jumlah”, “Kategori”, dan “Catatan”. Perlu diingat bahwa layanan tempat Anda mengirimkannya akan melihat pengeluaran Anda.
