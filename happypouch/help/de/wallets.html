Geldbörsen und Währungen

Eine Währung ist das, in dem Sie Geld zählen. Eine Geldbörse ist der Ort, an dem es liegt: Bargeld, eine Karte, eine Einlage. Geldbörsen sind optional: Sie können auch alles in einer Währung erfassen.

Währungen

„Einstellungen“ → „Währungen“. Beim ersten Start legt die App die Währung Ihres Landes an.

  • Hinzufügen: die „+“-Schaltfläche in der Abschnittsüberschrift. Ein Name oder ein Code genügt: „USD“, „Euro“.
  • Heimat: die Währung, die Sie gerade betrachten. Markieren Sie sie in der Liste; „Start“, „Einträge“ und „Statistik“ zeigen die Einträge in ihr.
  • Anfangsbestand: der Betrag, ab dem die Erfassung beginnt. Danach wird der Kontostand für Sie berechnet.
  • Untere Kontostandsschwelle: eine optionale Grenzlinie. Nähert sich Ihr Geld ihr, wird der Betrag „Verfügbar“ gelb; darunter rot.

Beim Löschen einer Währung werden alle Einträge, Zahlungen und Geldbörsen in ihr gelöscht. Die letzte Währung lässt sich nicht löschen.

Geldbörsen

„Einstellungen“ → „Geldbörsen“ → „+“. Eine Geldbörse hat einen Namen, eine Währung, einen aktuellen Kontostand und ein Symbol.

  • Es können beliebig viele Geldbörsen sein: zwei Karten, Bargeld, eine Einlage.
  • Jede Geldbörse hat ihre eigene Währung. Bargeld in Euro und Bargeld in Dollar sind zwei Geldbörsen.
  • Krypto können Sie genauso erfassen: Legen Sie eine Währung wie USDT an und eine Geldbörse darin. Beträge werden mit zwei Nachkommastellen gespeichert, daher lassen sich kleine Bruchteile eines Bitcoin nicht erfassen.

So ordnen Sie einen Eintrag einer Geldbörse zu

In der Eintragskarte erscheinen unter dem Betrag Schaltflächen für die Geldbörsen dieser Währung. Tippen Sie auf die gewünschte. Wählen Sie keine, hat der Eintrag keine Geldbörse: Er zählt zum Gesamtkontostand der Währung, aber zum Kontostand keiner Geldbörse.

So sehen Sie eine einzelne Geldbörse an

Öffnen Sie das Seitenmenü und wählen Sie die Geldbörse im Bereich „Geldbörse“. „Start“, „Einträge“ und „Statistik“ zeigen nur diese Geldbörse, und „Verfügbar“ zeigt ihren Kontostand. „Alle Geldbörsen“ bringt die Gesamtansicht zurück.

Überweisungen

Eine Überweisung bewegt Geld von einer Geldbörse in eine andere und zählt weder als Ausgabe noch als Einnahme.

  • Für eine Überweisung nutzen Sie das Symbol mit den zwei Pfeilen neben dem Betrag „Verfügbar“ auf „Start“ oder die Schaltfläche in „Einträge“ neben den Geldbörsen.
  • Überweisungen funktionieren nur zwischen Geldbörsen derselben Währung. Ein Währungstausch lässt sich noch nicht als Überweisung erfassen.
  • Die Überweisungen des Zeitraums stehen am Ende von „Einträge“. Tippen Sie auf eine Überweisung, um sie zu ändern oder zu löschen.

Wenn Sie eine Geldbörse löschen

Die Einträge bleiben, aber ohne Geldbörse. Überweisungen von und zu ihr werden gelöscht.
