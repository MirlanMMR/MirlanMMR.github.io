Aide de Happy Pouch · Convertisseur de devises

Convertisseur de devises

Le convertisseur fonctionne comme le panneau d'un bureau de change : chaque devise a un prix d'achat et un prix de vente. Vous saisissez vous-même les taux ; l'application ne les télécharge pas et fonctionne sans internet.

Où il se trouve

Ouvrez le menu latéral : le bouton à trois barres en haut à gauche sur « Accueil », dans « Enregistrements » ou dans « Statistiques ». Le convertisseur se trouve sous le choix de la période.

Devise locale

Tous les taux sont exprimés par rapport à la devise locale, celle dans laquelle vous tenez vos comptes en ce moment. Elle s'affiche sous forme de bouton avec un drapeau au-dessus du champ du montant. Pour la changer, allez dans « Réglages », section « Devises », et marquez celle qu'il vous faut comme « Locale ».

Comment ajouter une devise

Touchez « + Devise » sous le panneau et saisissez un nom ou un code : « USD », « euro », « yen ». La devise apparaît dans la liste ; la devise locale ne change pas.

Comment saisir un taux

Chaque devise du panneau a deux champs :

ChampQuoi y écrire
AchatCombien de devise locale le bureau de change vous donne pour une unité de cette devise.
VenteCombien de devise locale le bureau de change vous prend pour une unité de cette devise.

Exemple : la devise locale est l'euro, et le panneau du bureau de change affiche le dollar à 0,91 / 0,93. Écrivez 0,91 dans « Achat » et 0,93 dans « Vente ».

Un seul champ suffit : ce prix est alors utilisé dans les deux sens. Un champ vide ou un zéro signifie qu'il n'y a pas de taux. Un taux est enregistré aussitôt ; il n'y a pas de bouton « Enregistrer ».

Comment convertir un montant

  1. Saisissez le montant dans le champ au-dessus du panneau. Vous pouvez calculer sur place : 100+50.
  2. Le résultat dans l'autre devise apparaît à droite.
  3. La flèche entre les deux inverse le sens : le résultat devient le nouveau montant et le calcul se fait en sens inverse.

Sous le résultat, il est dit quel prix a été utilisé, par exemple « $ – Achat ».

Pourquoi reconvertir donne un autre résultat

Parce qu'un bureau de change fonctionne ainsi : il achète moins cher qu'il ne vend. Quand vous changez des dollars en euros, le bureau achète chez vous, donc le prix d'achat est utilisé. Quand vous changez des euros en dollars, il vend chez vous, donc le prix de vente est utilisé. L'application choisit le prix selon le sens de la flèche.

Pour utiliser l'autre prix, touchez son champ sur le panneau. Il s'allume et le calcul l'utilise.

Comparer deux devises entre elles

Touchez le prix d'une devise, puis celui d'une autre, par exemple le dollar et la livre. Le calcul garde ces deux-là, sans la devise locale. Pour ramener la devise locale, touchez son bouton avec le drapeau au-dessus du champ du montant.

Inutile de saisir un taux direct entre elles : l'application passe par la devise locale. Si une nouvelle devise n'a pas encore de taux avec la devise locale, mais en a un avec une autre devise qui en a un, le calcul passe par celle-ci.

Ce qui arrive aux taux

  • Ils sont stockés uniquement sur le téléphone et entrent dans la sauvegarde avec les enregistrements.
  • Ils ne se mettent pas à jour tout seuls : si un taux a changé, corrigez le chiffre sur le panneau.
  • Quand vous changez la devise locale, inutile de ressaisir les taux : l'application les recalcule en sens inverse.
  • Si vous supprimez une devise, ses taux sont supprimés avec elle.

Le convertisseur n'écrit rien dans les dépenses ni les revenus. C'est une calculatrice : elle calcule combien vous obtenez lors d'un change, mais n'enregistre pas le change lui-même.
