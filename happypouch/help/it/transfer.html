Passare da un'altra app

Le voci di un'altra app di budget si trasferiscono con un unico file. Categorie e valute vengono create per te, quindi non serve ripartire da zero.

Cosa viene trasferito

  • Voci di spesa e di entrata: data, importo, categoria, sottocategoria, valuta, nota.
  • Categorie e valute che non hai ancora. L'app le crea e ti mostra l'elenco prima dell'importazione.

I trasferimenti tra portafogli non vengono importati: sono saltati, e l'app ti dice quanti erano. Le voci che sono già in Happy Pouch non vengono aggiunte una seconda volta.

Passo 1. Esporta un file dalla tua vecchia app

Cerca «Esporta» nella vecchia app, di solito in Impostazioni o in una sezione dati. Excel (XLSX) e CSV funzionano meglio. Salva il file sul telefono.

Serve un'esportazione in una tabella (un foglio di calcolo), non un «backup». Happy Pouch non può leggere il backup di un'altra app.

Passo 2. Apri il file in Happy Pouch

«Impostazioni» → «Trasferimento dati» → «Scegli file». In un'app ancora vuota lo stesso pulsante è in «Home»: «Trasferisci dati / importa estratto conto».

Non vedi il file nell'elenco? Il selettore di file si apre dove eri l'ultima volta, spesso in «Foto». Tocca ☰ in alto a sinistra e apri «Recenti»: un file appena ricevuto è lì. Per un file inviato tramite WhatsApp o Telegram, guarda anche in «Download» o «Documenti». Se non è in «Recenti», apri il file nell'app di messaggistica e salvalo sul telefono, poi riprova.

Passo 3. Controlla le colonne

Si apre la schermata «Importa transazioni». In alto dice che tipo di file sembra e quante righe ha. Sotto c'è l'elenco dei campi dell'app: «Data», «Importo», «Categoria», «Sottocategoria», «Valuta», «Nota». L'app ha già abbinato a ogni campo una colonna del tuo file in base alla sua intestazione.

Come vedere quale colonna è scelta. A destra di ogni campo c'è un pulsante arrotondato con un contorno. Mostra il nome della colonna del tuo file, per esempio «Data» o «Data della transazione». Se mostra un trattino «—», per quel campo non è scelta nessuna colonna.

Come scegliere un'altra colonna. Tocca quel pulsante a destra del campo. Si apre un elenco: la prima riga è «— non usare», poi tutte le colonne del tuo file. Tocca quella che ti serve. Per esempio, il campo «Data» mostra «Data di creazione» e ti serve «Data della transazione»: tocca il pulsante e scegli «Data della transazione».

Come controllare il risultato. Sotto l'elenco dei campi c'è scritto: «Prima riga del file: data …, importo …». È ciò che l'app ha letto dalla prima riga del tuo file con le colonne scelte. Se la data o l'importo lì sembrano sbagliati, cambia la colonna del campo corrispondente.

  • Se nel file spese ed entrate sono in due colonne diverse, passa da «Una colonna per l'importo» a «Entrate e spese separate». Allora compaiono due campi al posto del singolo «Importo»: «Colonna spese» e «Colonna entrate».
  • Se il file non ha una colonna con il tipo, gli importi negativi contano come spese e quelli positivi come entrate.
  • Se un campo non serve (per esempio «Sottocategoria»), scegli «— non usare» nel suo elenco.

Per date come 05/10/2026, imposta l'ordine della data sotto l'elenco: «Auto», «Giorno/mese» o «Mese/giorno». Di solito basta «Auto».

Se il file non ha una colonna della valuta, scegli una valuta per tutte le voci qui sotto toccando il pulsante con il suo codice.

Passo 4. Controlla il riepilogo e importa

Prima dell'importazione, l'app mostra cosa succederà: quante voci verranno aggiunte e per quale periodo, quante verranno saltate e perché, e quali categorie e valute verranno create. Sotto ci sono tre voci di esempio. Se tutto sembra giusto, tocca «Importa».

Quali file funzionano

FormatoDa dove viene di solito
Excel XLSX e XLSesportazione dalla maggior parte delle app di budget; l'opzione più affidabile
CSVesportazioni di app, estratti conto; separatore e codifica sono rilevati automaticamente
OFX, QFX, QBOestratti conto bancari
QIFprogrammi di finanza più vecchi
SQLitedatabase di GnuCash e Money Manager

Il file può pesare fino a 30 MB.

Se non funziona

  • «Questa non è una tabella ma un file proprietario». Hai scelto il backup di un'altra app. Torna in quell'app e cerca un'esportazione in CSV o Excel.
  • «Questo è un file JSON». È un backup di Happy Pouch stessa. Ripristinalo invece da «Impostazioni»: «Backup su questo telefono» → «Ripristina».
  • Date o importi non riconosciuti. L'app mostra esempi di queste righe. Controlla che siano scelte le colonne giuste per la data e l'importo, e che l'ordine giorno/mese sia corretto.
  • Le colonne sono confuse, o ce ne sono troppe. Apri il file in Excel o Fogli Google e tieni solo le colonne «Data», «Importo», «Categoria» e «Nota».

Se il formato del file è sconosciuto o disordinato, puoi darlo a un assistente IA e chiedergli di trasformarlo in una tabella CSV con le colonne «Data», «Importo», «Categoria» e «Nota». Tieni presente che il servizio a cui lo invii vedrà le tue spese.
